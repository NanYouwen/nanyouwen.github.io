AI 的记忆，该记什么、不该记什么

AI 的“记忆”听起来很像一个人记住了你，但实际更像一组被保存下来、以后可能被再次拿出来的资料。它可能是当前对话前面的内容，也可能是你主动保存的偏好、一个项目的背景、某份知识库里的文档。把这些东西都叫记忆容易产生误解：不是记得越多越聪明，也不是所有过去的信息都应该一直留下。

我比较喜欢先问一句：这条信息下一次真的会帮助任务吗？如果答案只是“也许有一天会用到”，通常不值得长期保存。记忆会占用上下文，也会带来隐私和过期风险。一个已经离职的联系人、早已更换的项目规则、临时的情绪表达，若被不加区分地带进未来对话，反而会让 AI 做出不合时宜的假设。

把记忆分成几层

最短的一层是本次会话上下文。你正在讨论的文件、问题、刚刚确认的目标，都属于这里。它的作用是让对话连贯，任务结束后通常没有必要永久保留。第二层是项目记忆，例如技术栈、文档位置、发布限制、写作风格。它与一个具体项目绑定，应该有负责人和更新时间。

第三层是个人偏好，例如你习惯使用的语言、输出格式、是否希望先看草稿。这类信息能减少重复沟通，但也要允许修改和关闭。最后还有一层是不应保存的信息：密码、身份证号、私密聊天内容、未经同意的他人资料、短期授权链接等。即使它们能让回答更方便，也不应该成为 Agent 的长期背景。

这种分层的好处是，数据一进来就能知道它该待多久。一次会议上的临时决定，可能只需要留到会议纪要确认；一份项目规范可留到下次修订；个人偏好随时可查看、编辑和删除。没有期限的记忆，最容易在不知不觉中变成负担。

记住“来源”和“时间”

一条没有来源的记忆很危险。比如 AI 说“这个项目不允许使用某个服务”，我们应该能追问：这是来自哪份文档、谁在什么时候确认的、现在是否仍然有效。比起只保存一句结论，更有用的是保存结论、来源链接、记录日期和适用范围。这样当规则改变时，能找到该更新的地方，而不是让旧说法继续影响新的任务。

时间尤其重要。产品价格、团队成员、接口权限、法律政策、模型能力都可能变化。对于容易过期的信息，可以在记忆里标上“截至某日有效”或“每季度复核”。这不是让 AI 变笨，而是防止它把去年的答案当成今天的事实。

不要把记忆当成秘密抽屉

有些人把每次对话、每份资料都塞进知识库，希望 AI 以后“什么都懂”。但资料越多，检索越可能拿到相似却不适用的内容；错误或过期的信息也会获得新的生命。更稳的做法是先整理：删掉重复，标出权威来源，给文档起清楚的名字，区分公开、内部、敏感三个范围。AI 的记忆质量，常常取决于人是否愿意先做这点整理。

对团队而言，还应当明确谁可以添加、谁可以查看、谁能删除。记忆并不是一个没有主人的公共黑板。涉及客户、员工、财务或账号信息时，默认不保存比默认保存更安全。真的需要使用，也应先确认数据范围和权限。

一个简单的保存判断

在把信息交给 AI 长期保存前，我会过一遍这四个问题：

  1. 它会在未来的哪类任务中被重复使用？
  2. 它来自哪里，何时记录，多久需要复核？
  3. 里面是否含有不该长期保存的个人或敏感信息？
  4. 谁能够看见、修改和删除它？

如果其中任意一项回答不出来，就先把它留在当前任务里，而不是急着写进记忆。好的记忆不是一间越堆越满的仓库，而是一张能让人和 Agent 都找到正确资料、也能随时清理旧内容的地图。

给记忆一个定期整理的机会

记忆库也需要像项目文档一样维护。可以每月或每个阶段结束时看一眼：哪些内容已经过期，哪些重复，哪些项目已经结束，哪些偏好已经改变。整理时不必逐条阅读全部资料，先从最近最常被引用的、容易变化的、带有敏感标签的内容开始即可。

删除并不是损失。有些内容留在可搜索的历史档案里就足够，不必继续作为 Agent 每次任务的默认背景；有些信息在失效后就应该彻底移除。给用户提供“查看我被记住了什么”和“删除这条”的入口，也能让记忆从一个黑箱变成可协商的工具。

当系统能清楚地区分临时、长期、敏感和过期信息时，人会更敢把合适的事情交给它。真正好的 AI 记忆不是表现得什么都记得，而是知道什么值得带到下一次、什么应该留在过去。

记忆出错时怎样纠正

AI 有时会把一条旧偏好当成现在的事实，或者把临时结论记得太牢。遇到这种情况，最好的体验不是让用户重新解释十遍，而是能直接看到它依据的记忆、修改或删除对应条目，并在下一次任务中生效。可见、可编辑、可撤回，是长期记忆比普通聊天更值得拥有的能力。

对项目记忆来说，也可以在重要规则变化时留下“替换关系”：旧规则何时失效，新规则从哪份文档开始生效。这样检索或 Agent 读取时，不会把两者平铺在一起让模型猜。人维护知识时常犯的错是只新增不更新，AI 记忆同样需要避免这种积灰。

让错误可以被修正，会让人更愿意信任记忆系统。因为信任不是相信它永远不误会，而是相信一旦误会，自己有清楚而有效的方式把它改回来。

对于多人共用的 Agent，最好再区分“我的偏好”和“团队规则”。前者不应被默认推广给所有人，后者也不该被任何一次个人对话随意改掉。把作用范围标清，能减少记忆带来的意外影响。

记忆越接近人的长期习惯，越需要尊重选择权。让保存有理由、删除有入口、更新有记录，AI 才能在帮助之外，也保留让人安心的距离。
